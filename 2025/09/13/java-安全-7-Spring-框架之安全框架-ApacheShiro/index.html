java安全7-Spring框架之安全框架Apache Shiro

Apache Shiro

Apache Shiro是一个轻量级、功能强大且易于使用的Java安全框架，广泛用于认证、授权、会话管理和加密，API简洁、配置简单、上手快，使用时添加依赖shiro-spring-boot-web-starter并有Realm类获取用户的身份信息和权限信息

框架识别

请求包cookie中存在rememberMe字段

响应包中存在rememberMe=deleteMe字段

权限绕过漏洞

在 1.1.0 之前和 JSecurity 0.9.x 之前，不会对与shiro.ini条目进行对比前的URI路径进行规范化，因此有了可以绕过访问权限的机会

身份认证绕过与反序列化漏洞

shiro1.2.5版本之前，没有为“remember me”功能配置密钥，基本使用默认密钥，执行任意代码（反序列化等等）或通过请求参数绕过预期的访问限制

CVE-2016-4437

RememberMeManager提供rememberMe功能，其中AbstractRememberMeManager重写了该接口，从中发现了AES加密的密钥

代码中看到通过resolvePrincipals函数解析rememberMe参数

解析时若无法获取用户身份，通过getRememberedIdentity函数获取用户身份

到此已经无法解析rememberMe参数，所以去到getRememberedPrincipals函数

rememberMe参数不为空就调用convertBytesToPrincipals函数解析，以此传入二进制数据

将二进制数据解码，再deserialize反序列该值，为最终的利用点，可以利用反序列化链（CC链）

反序列化工具ysoserial

地址：https://github.com/frohoff/ysoserial

该工具具有各种java反序列化利用链，能直接生成序列化数据文件，能通过交互开启各种服务，例如监听等，用来提供真正的payload

利用过程

payload要先利用序列化链进行rce（反弹），再将rememberMe用源码中的密钥进行AES加密，通过目标机主动连接ysoserial设置的反序列陷阱，利用各种CC链将ysoserial中的真正payload传给目标机，让目标机执行反弹命令，实现利用

在源码中能看到CC1链的重写transform方法ConstantTrasformer、ChainedTransformer、InvokerTransformer等等，用ysoserial利用CC1链构造payload

源码中有CommonsBeanutils编译源码，且shiro550中自带CommonsBeanutils 1.8.3 和 commons-collections-3.2.1，所以可以利用CB链，CB链执行代码，而CC链执行命令，所以CB链更稳定
