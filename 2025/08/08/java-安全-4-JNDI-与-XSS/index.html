java安全4-JNDI与XSS

JNDI

JNDI（java naming ang directory interface）是Java命名接口系统，分为命名服务和目录服务，用来定义用户、网络、机器、对象和服务等各种资源

命名服务就是通过名称来查找实际对象的服务，例如RMI（Bindings）与DNS，概念：Bindings（名称与对象一一对应）、Context（在上下文中查找对象）、References（通过引用与对象对应）

目录服务除了可以名称查找（Lookup）外还添加了属性（Attributes），还可以通过属性搜索（Search）对象，支持LDAP、DNS、RMI等等
